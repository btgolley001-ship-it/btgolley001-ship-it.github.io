  1. HTML is a HyperText Markup Language
    1. Formatting text is done through tags. Changes appearance and attributes.
    2. Hypertext (where we get the term "hyperlink," the contained link itself) contains information about other text.
  2. There are many types of tags in HTML with different properties.
    1. Block tags start new lines; inline/text-level tags can modify text within a line.
    2. Most tags have a start and end which wrap around the text they modify.
    3. Standalone tags, like linebreaks and horizontal lines, have no start or end. They are as they are.
  3. There are many different ways to display text.
    1. Paragraphs, headings, etc. All things you can do to basic text (i.e. emphasis, strong, etc.) also apply to other forms.
    2. Lists! Can nest into each other. And tables: which don't. But are a bit more customizable in shape.
    3. Multimedia components like images and videos function like in-line standalone tags, and can be embedded into a page.
